# 체육교사 보조 프로그램(통합판) → 줄넘기 전국 현황판 연동 작업 설명서

이 글은 통합 프로그램(저장소 MusicalPE/pe-assistant, 화면 MusicalPE/pe-app)의 **줄넘기 모듈(Mod_Rope.gs)** 에
"전국 현황판 참여" 기능을 넣기 위한 설명서입니다.
현황판·기록실·수집기는 **줄넘기 기록 관리(MusicalPE/jumprope)** 에 이미 있고, 두 프로그램 학교가 **같은 현황판에서 함께** 겨룹니다.
통합 프로그램 쪽은 "보고 보내기 + 설정 화면 + 링크"만 만들면 됩니다. 수집기·현황판은 고치지 않습니다.

---

## 1. 전체 구조

```
[줄넘기 기록 관리 학교들] ─┐
                           ├─ POST report ─→ [수집기 Collector.gs (운영자 시트 1개)] ─→ board.html / hall.html
[통합 프로그램 학교들] ────┘                         (MusicalPE/jumprope 소유)        (https://musicalpe.github.io/jumprope/)
```

- 수집기 주소는 고정하지 말고 **https://musicalpe.github.io/jumprope/national.json** 의 `"collector"` 값을 읽어 쓸 것
  (수집기를 다시 배포해 주소가 바뀌어도 jumprope 쪽 national.json 만 고치면 두 프로그램 모두 따라감).
  서버에서 `UrlFetchApp.fetch` 로 읽고 CacheService 에 6시간 정도 저장.
- 통합 프로그램은 이미 `script.external_request` 권한이 있으므로(Gemini·업데이트 확인에 사용 중) **서버(Apps Script)에서 보낸다.**
  → 학교 키·담당 교사 정보가 학생/브라우저 쪽에 드러나지 않음. 학교에서 권한을 다시 승인할 필요 없음.

## 2. 수집기 요청 형식 (꼭 이대로)

### 보고 (report)
```js
var res = UrlFetchApp.fetch(collectorUrl, {
  method: 'post',
  contentType: 'text/plain;charset=utf-8',
  payload: JSON.stringify({ fn: 'report', args: [payload] }),
  followRedirects: true,
  muteHttpExceptions: true
});
var j = JSON.parse(res.getContentText());   // { ok: true, result: { publicId, days, contactSet } } 또는 { ok: false, error }
```

`payload`:
```js
{
  key: '학교 비밀키',          // 16자 이상. 처음 참여할 때 Utilities.getUuid() 로 한 번 만들고 계속 같은 값 사용
  showName: true/false,        // 현황판에 학교 이름 공개 여부
  name: showName ? 학교이름 : '',   // 현황판에 보일 이름 (공개 안 하면 빈 문자열)
  schoolName: 학교이름,        // 운영자만 보는 진짜 이름 (항상 보냄)
  teacher: 담당교사,           // 운영자만 봄. 비어 있으면 수집기는 기존 값을 그대로 둠
  contact: 연락처,             // 선택. teacher 와 함께 보낼 때만 저장됨
  registered: 등록학생수,      // 줄넘기 대상 학년의 학생 수 (1인당 평균·참여율 계산에 씀)
  app: 'pe-assistant ' + 버전, // 참고용 (수집기는 무시)
  days: [
    { date: 'yyyy-MM-dd', students: [ [학생키, 가린이름, 학년, 횟수, 카메라횟수], ... ] },
    ...
  ]
}
```

- `days` 는 **이번 달 + 지난 달** 날짜만(그 밖은 수집기가 버림). 오늘 이후 날짜도 버림. 최대 70일.
- 같은 학교·같은 날짜는 **새 값으로 덮어씀** → 매번 그날 전체 합계를 보내면 됨(더하기 아님).
- 날짜는 한국 시간(Asia/Seoul) 기준 `yyyy-MM-dd`.
- 학생 한 줄 = `[학생키, 가린이름, 학년, 그날 합계 횟수, 카메라 인증 횟수]`
  - 통합 프로그램에는 카메라 판정기가 없으므로 카메라 횟수는 `0`.
  - 학년은 문자열(예: `'5'`). 4자까지.
  - 하루 학생 최대 1200명, 한 학생 하루 최대 30000회 (넘으면 수집기가 자름).
- **상태가 '확인' 인 기록만** 합산 (대기·반려·짝대기·짝반려 제외). 종류(모아뛰기 등)는 구분 없이 모두 더함.

### 참여 끄기 (leave)
```js
payload: JSON.stringify({ fn: 'leave', args: [{ key: 학교비밀키 }] })
```
→ 수집기에서 그 학교 자료(Schools·Daily)를 모두 지움.

## 3. 계산 규칙 (줄넘기 기록 관리와 똑같이)

```js
function sha256hex_(s) {
  return Utilities.computeDigest(Utilities.DigestAlgorithm.SHA_256, String(s), Utilities.Charset.UTF_8)
    .map(function (b) { var v = (b + 256) % 256; return (v < 16 ? '0' : '') + v.toString(16); }).join('');
}
// 학교 공개 번호 (현황판 주소의 ?me= 에 씀)
function natPublicId_(key) { return sha256hex_('jr-school|' + key).slice(0, 10); }
// 학생 키 (학생ID 를 그대로 내보내지 않기 위해)
function natStudentKey_(key, 학생ID) { return sha256hex_('jr-student|' + key + '|' + 학생ID).slice(0, 10); }
// 이름 가리기: 김하늘 → 김*늘, 이준 → 이*, 남궁민수 → 남**수
function natMask_(n) {
  var c = Array.from(String(n || '').trim());
  if (c.length <= 1) return c.join('');
  if (c.length === 2) return c[0] + '*';
  return c[0] + new Array(c.length - 1).join('*') + c[c.length - 1];
}
```
- 이름은 **반드시 보내기 전에 가린다** (수집기도 한 번 더 가리지만, 실명이 밖으로 나가면 안 됨).
- 반·번호·실명·학생ID·비밀번호는 보내지 않는다.

## 4. 통합 프로그램에 넣을 것

### (1) 설정 저장
- `nat = { on, key, name, showName, teacher, contact }` 를 **학교 쪽 서버에만** 저장
  (통합 프로그램이 학교별 설정을 저장하는 기존 방식 사용 — 라이브러리 구조라 `PropertiesService.getScriptProperties()` 를
  라이브러리에서 직접 부르면 라이브러리 것이 될 수 있으니, 기존 설정 도우미(속성_/설정 시트)를 따를 것).
- 학생용 API·공개 응답에는 key·teacher·contact 를 **절대 넣지 않는다.** 교사 화면에도 key 는 보여 줄 필요 없음.

### (2) 교사 화면 (Rope_T.html 설정 부분)
줄넘기 기록 관리의 관리자 → "전국 현황판" 탭과 같은 내용:
- [ ] 전국 현황판에 참여하기 (기본 꺼짐)
- 학교 이름 * / 담당 교사 * / 연락처 (선택)
  - 참여를 켤 때 학교 이름·담당 교사가 비어 있으면 저장 막기
- [ ] 현황판에 학교 이름 공개 (끄면 "익명 학교 ABCD")
- 안내 상자 3칸: 현황판에 보내는 것(가린 이름·학년·날짜별 횟수·등록 학생 수) / 운영자만 보는 것(학교 이름·담당 교사·연락처) / 보내지 않는 것(학생 실명·반·번호·비밀번호·그 밖의 시트 내용)
- 버튼: 저장 · 지금 보내기 · 현황판 보기 → · 기록실 →
  - 현황판: `https://musicalpe.github.io/jumprope/board.html?me=<공개번호>`
  - 기록실: `https://musicalpe.github.io/jumprope/hall.html?me=<공개번호>`
- 참여를 끄면 확인 창 → leave 보내기 → "현황판에서 우리 학교 기록을 지웠습니다"
- 결과 문구: "보냈어요. (N일치) 현황판에는 몇 분 안에 반영됩니다." (현황판은 5분 캐시)

### (3) 보고 시점
- 교사가 **저장 / 지금 보내기** 를 누를 때: 이번 달+지난 달 전체를 보냄
- 기록이 **'확인' 상태가 될 때**(교사 확인, 교사 직접 입력, 자동확인으로 학생 입력이 바로 확인될 때): 그 기록 날짜의 하루치를 보냄
  (자주 몰리면 CacheService 로 1~2분에 한 번만 보내도록 묶어도 됨)
- 교사가 줄넘기 화면을 열 때: 마지막 전체 보고 후 1시간이 지났으면 이번 달+지난 달 전체를 한 번 더 (늦게 넣은/고친 기록 반영)
- 보고 실패가 기록 저장을 **절대 막으면 안 됨**: try/catch 로 감싸고 실패는 조용히 넘기거나 교사 화면에만 알림
- 기록 수정·삭제·반려로 합계가 줄어도 다음 전체 보고 때 덮어써져 맞춰짐

### (4) 학생·메인 화면 (선택)
- 참여 중이면 줄넘기 화면에 "전국 현황판" 링크 버튼 (`board.html?me=<공개번호>`)

## 5. 운영자(음악적체육인) 쪽에서 보이는 것
- 수집 시트 Schools: PublicId, Name(공개명), ShowName, Registered, FirstSeen, LastSeen, Hidden, SchoolName, Teacher, Contact
- Daily: 학교·날짜별 합계와 학생 목록(가린 이름)
- 장난 보고 → Schools 의 Hidden 칸에 1, 바로 반영하려면 수집기 편집기에서 `refreshCache` 실행
- 두 프로그램 학교가 한 목록에 섞여 보임 (구분이 필요하면 학교 이름으로)

## 6. 확인 순서 (구현 후)
1. 시험용 학교에서 참여 켜기 → "보냈어요" 문구
2. 수집 시트 Schools 에 줄이 생기고 SchoolName·Teacher 가 들어왔는지
3. Daily 에 날짜별 줄, Students 칸 이름이 가려져 있는지(김*늘)
4. 현황판(5분 안)·기록실(지난 달 자료가 있으면)에 학교가 보이는지
5. 참여 끄기 → Schools·Daily 에서 사라지는지

## 7. 하지 말 것
- 수집기 주소를 코드에 박아 두기 (national.json 에서 읽기)
- Collector.gs·board.html·hall.html 고치기 (jumprope 저장소 몫 — 바꿔야 하면 그쪽에서)
- 학생 브라우저에서 수집기로 직접 보내기 (학교 키가 드러남)
- 실명·반·번호·학생ID 보내기
