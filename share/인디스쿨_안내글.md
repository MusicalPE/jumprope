안녕하세요, 음악적체육인입니다. 🙂

줄넘기 기록을 학생들이 **휴대폰으로 직접 넣고**, 반 전체 그래프와 학생별 누적을 한눈에 보는 프로그램을 나눕니다.
이번 2.1 에서는 **전국 현황판**이 생겨서, 참여하는 학교끼리 **한 달 단위로 순위**를 겨룰 수 있어요.

## 이런 분께 좋아요
- 줄넘기 인증제·아침 운동·방과후 줄넘기 기록을 종이로 걷고 계신 분
- 학생들이 "오늘 몇 개 뛰었는지" 스스로 쌓아 가는 재미를 주고 싶은 분
- 다른 학교 친구들과 겨루는 자극이 필요한 분 (전국 현황판)

## 주요 기능
- 📱 **학생 입력**: QR 찍고 → 학년·반·이름·종류 고르고 → 횟수 저장. 로그인 필요 없음
- 📊 **우리 반 화면**: 이번주·오늘의 줄넘기왕, 연속 기록 1위, 학생별 누적 그래프(종류별로 쌓아서)
- 📷 **카메라 판정기**(선택): 카메라가 실제로 뛴 횟수를 세서 자동 기록
- ✅ **승인 절차**(선택): 학생 입력 → 선생님 승인 후 반영
- 🏆 **전국 현황판 (NEW)**: 학교 순위 + 학교 안 학생 순위, 한 달 단위(매달 1일 새로 시작)
- 🏅 **기록실 (NEW)**: 지난 달 학교·학생 1~3등이 차곡차곡 남아요
- 🔄 **자동 업데이트**: 학교 시트에는 껍데기 하나만. 새 기능은 저절로 들어옵니다

## 전국 현황판 참여 안내 🏆
**언제부터?** 지금 바로! 이번 달 기록부터 집계되고, **매달 1일에 새로 시작**합니다.
지난 달 1~3등 학교·학생은 **기록실**에 올라가요.

**어떻게 참여하나요?**
1. 아래 첨부파일로 설치 (이미 v2 를 쓰고 계시면 설치할 것 없음)
2. 관리자 메뉴 → **전국 현황판** 탭 → "전국 현황판에 참여하기" 체크 → 저장
3. 학교 이름을 보이게 하려면 "학교 이름 공개"도 체크 (끄면 "익명 학교 ABCD")

**공정하게 겨뤄요**
- 학생 수가 많은 학교가 무조건 이기지 않도록 **합계 · 1인당 평균 · 참여율** 세 가지 순위를 함께 보여 줍니다.
- 카메라 판정기로 인증된 횟수는 📷 로 따로 표시돼요.

**개인정보는 이렇게 지켜요**
| 현황판에 보내는 것 | 보내지 않는 것 |
|---|---|
| 가린 이름(예: 김*늘), 학년, 날짜별 횟수, 카메라 인증 횟수, 등록 학생 수 | 실명, 반, 번호, 비밀번호, 그 밖의 시트 내용 |

- 참여·학교 이름 공개 모두 **기본 꺼짐**이고, 선생님이 켜야만 보내집니다.
- 참여를 끄면 현황판에 올라간 우리 학교 기록은 **바로 지워집니다**.
- 학생 기록 원본은 **선생님 구글 드라이브 시트**에만 있어요.

👉 전국 현황판: https://musicalpe.github.io/jumprope/board.html
👉 기록실: https://musicalpe.github.io/jumprope/hall.html

## 설치 (5분, 한 번만)
1. 구글 드라이브 → 새 스프레드시트 → 확장 프로그램 → Apps Script
2. `Code.gs` 내용을 지우고 첨부의 **Shell(껍데기).txt** 내용을 붙여넣기 → 저장
3. 배포 → 새 배포 → 웹 앱 (실행: **나** / 액세스: **모든 사용자**) → 권한 허용
4. 나온 주소를 열고 **프로그램 열기** → 즐겨찾기. 관리자 비밀번호는 처음에 `1234`

자세한 내용(학생 엑셀 붙여넣기 등록, QR, 1.x 에서 옮기기, 문제 해결)은 첨부한 **사용설명서.pdf** 에 그림과 함께 정리해 두었어요.
