줄넘기 기록 관리 · 전국 줄넘기 현황판 Jump Earth(점퍼스) 개발 이야기
— 최종 연구보고회 자료 (음악적체육인, 2026년 10월 정리)

※ [ ] 표시는 선생님께서 직접 채워 주실 부분입니다.


■ 1. 왜 만들었나

- 줄넘기 인증제·아침 운동 기록을 종이로 걷고, 교사가 손으로 합산하던 불편함
- 학생이 "내가 얼마나 뛰었는지"를 바로 보지 못해 꾸준히 하려는 동기가 약함
- 비싼 유료 서비스 대신, 학교가 이미 쓰는 구글 계정·스프레드시트만으로 돌아가는 무료 도구가 필요했음
- 교사가 직접 만들고 고칠 수 있도록, 프로그래밍 전문 지식 없이 AI와 대화하며 만드는 "바이브코딩" 방식을 택함
  (이 프로그램이 음악적체육인의 첫 바이브코딩 프로그램)


■ 2. 어떻게 만들었나 (개발 방식)

- 교사가 수업 현장에서 필요한 것을 말로 설명 → AI(Claude)가 코드로 만들고 → 교사가 실제 학교 시트에서 써 보고 → 불편한 점을 다시 말하는 과정을 반복
- 큰 기능은 먼저 "베타(실험판)"에 올려 교사가 시험해 본 뒤 괜찮은 것만 "정식판"에 넣음
- 화면 디자인·로고·글꼴처럼 취향이 들어가는 부분은 여러 안을 나란히 비교한 그림을 보고 교사가 고름
- 바뀐 내용은 프로그램 안 "업데이트 내역"에 판 번호와 함께 남김
- 모든 코드는 GitHub(MusicalPE/jumprope)에 올려 기록이 남고, 누구나 확인할 수 있음


■ 3. 발전 과정 (판별 주요 내용)

[1단계] 학급용 기록 프로그램 (1.x, 2026년 8~9월)
- 1.1 첫 배포: 링크 접속 → 학생 입력 → 선생님 승인 → 그래프 반영
- 1.2 이번주·오늘·연속 기록 1위 배너, 하루 목표
- 1.3 관리자 비밀번호, 여러 학생 한 번에 등록
- 1.4 줄넘기 종류별 기록과 그래프 / 1.4.1 AI(Gemini)가 매일 "오늘의 한마디" 응원 문구
- 1.5 카메라 판정기 연동: 카메라가 실제로 뛴 횟수를 세어 자동 기록
- 1.6 관리자 메뉴 탭 정리, 색 테마, 엑셀 붙여넣기 등록 / 1.6.1 학생 접속 QR

[2단계] 구조 전환 — "한 번 설치하면 업데이트는 자동" (2.0, 2026년 10월 4일)
- 학교 시트에는 짧은 "껍데기" 코드 하나만 두고, 화면과 기능은 GitHub에서 불러오게 바꿈
- 새 기능이 나와도 학교마다 코드를 다시 붙여 넣을 필요가 없어짐
- 1.x를 쓰던 학교의 학생·기록은 같은 시트에서 그대로 이어짐

[3단계] 전국으로 — 전국 줄넘기 현황판 (2.1, 10월 4일)
- 참여하는 학교끼리 한 달 단위로 순위를 겨루는 전국 현황판과, 지난 달 1~3등을 남기는 기록실(현 명예의 전당)
- 학교 이름·담당 교사 등록, 기록실 최근 12개월 보기
- 학생 수가 많은 학교만 이기지 않도록 합계·1인당 평균·참여율 세 가지 순위

[4단계] 수업 도구로 깊게 (2.2.0~2.2.3, 10월 5~6일)
- 줄넘기 급수 인증: 한국줄넘기협회 급수표(흰→노랑→초록→파랑→밤→주황→빨강→검은→와이어)를 교사가 항목별로 체크
- 급수 인증서·전국 순위 상장을 A4로 인쇄·PDF 저장
- 우리 반 줄넘기 여행: 1회=1m로 서울→부산, 국토 한 바퀴, 지구 한 바퀴
- 전국 "모두 함께 지구 한 바퀴"(학년도마다 새로 시작, 지난 학년도 거리 표시)
- 학년별 순위, 같은 학교 여러 반 참여
- 등록된 학생에 따라 "우리 반 / 우리 N학년 / 우리 학교"로 표현이 바뀜

[5단계] 쓰기 쉽게, 알아보기 쉽게 (2.2.4~2.2.11, 10월 6~8일)
- 바탕화면·휴대폰 홈 화면에 앱 아이콘으로 설치
- 구글 쪽 연결이 잠깐 끊겨도 자동으로 다시 시도
- 견본 시트 "사본 만들기"로 설치 단계를 5분 → 2분으로 줄임, 1분짜리 설치 영상(유튜브·쇼츠) 제작
- 전국 현황판 이름을 "Jump Earth(점퍼스)"로 짓고 로고·구호 제작
- 기록실을 "명예의 전당"으로 바꾸고 줄넘기 월계관 로고, 전국 1위를 여러 번 하면 상장의 별이 늘어나게 함
- 전국 순위 50등까지 팝업으로 보기
- 아이들 화면에 맞는 둥근 글꼴(주아·도현) 적용


■ 4. 현장 교사의 판단이 바꾼 것들 (사례)

- 전국 순위가 생기자 "학생이 마구 올리면 순위가 흔들린다"는 걱정 → 교사 승인을 기본으로 켜고, 승인을 끄면 전국 현황판에 참여할 수 없게 함
- 그러면서도 카메라로 센 횟수는 실제로 뛴 것이므로 승인 없이 바로 인정
- 급수는 "걸리지 않고 100회"처럼 교사가 직접 봐야 하므로 학생 입력이 아닌 교사 인증 방식, 앞 급수를 못 따면 다음 급수는 잠금
- 인증서 직함은 담임만이 아니라 체육 교사도 줄 수 있어 담임·체육 교사·직접 입력 중 선택
- 연속 기록 1위가 동점일 때 모두 보여 주기
- 한 반이 아니라 학년·학교 단위로 쓰는 경우를 고려한 "우리 반/학년/학교" 표현
- 안내 글에 이모티콘이 많으면 AI가 쓴 글처럼 보인다는 의견 → 담백한 문장으로 다시 씀
- 압축 파일 한글 이름이 깨져 풀리지 않던 문제 → 다시 묶음, 이후 첨부 없이 링크 중심으로 바꿈
- 설치 영상에 교사 개인정보(이메일·계정 사진·웹 앱 주소)가 보이지 않게 가림


■ 5. 프로그램 구조 (간단히)

- 학교 시트: 구글 스프레드시트 + 짧은 껍데기 코드(Apps Script). 학생·기록은 각 학교 선생님 드라이브에만 저장
- 화면: GitHub Pages(무료)에서 열림. 새 판은 모든 학교에 자동 반영
- 전국 현황판: 운영자 시트 하나(수집기)가 참여 학교의 요약만 받아 순위를 계산
- 카메라 판정기: 별도 프로그램(jump-rope-checker)이 횟수를 세어 기록으로 넘김
- 규모: 화면·서버 코드 약 5,800줄, 판 27개(1.1~2.2.11), GitHub 기록 68회(10월 4~8일 기준)


■ 6. 개인정보와 안전

- 현황판에 가는 것: 가운데 글자를 가린 이름(예: 김*늘), 학년, 날짜별 횟수, 카메라 인증 횟수, 등록 학생 수
- 운영자만 보는 것: 학교 이름, 담당 교사, 연락처(선택)
- 보내지 않는 것: 실명, 반, 번호, 비밀번호, 그 밖의 시트 내용
- 전국 참여와 학교 이름 공개는 기본으로 꺼져 있고, 참여를 끄면 현황판 기록은 바로 지워짐
- 다른 반 시트를 복사해 쓰면 알아채고 다른 반 기록을 덮어쓰지 않도록 막음
- 비싼 서버 없이 각 학교 드라이브에 자료가 있어 운영자가 학생 정보를 떠안지 않는 구조

■ 8. 어려웠던 점과 해결

- 구글 쪽이 잠깐 404 오류를 내며 "연결이 안 된다" → 원인을 단계별로 확인(배포·권한·시트), 자동 재시도와 안내 문구 추가
- 견본 사본을 만든 직후 권한 허용에서 "401 invalid_client" → 잠시 뒤 다시 하면 해결, 설명서 자주 묻는 질문에 추가
- 배포를 "새 배포"로 하면 주소가 바뀌는 문제 → 항상 "배포 관리 → 수정 → 새 버전" 안내
- 학교마다 업데이트를 해야 하는 부담 → 2.0에서 화면을 GitHub로 옮겨 근본적으로 해결
- 노설치 웹 서비스(파이어베이스)도 검토했으나, 학생 개인정보를 운영자가 떠안게 되어 지금 구조 유지로 결정
