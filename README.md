# 🏆 줄넘기 기록 관리 v2.2

학생들이 휴대폰으로 그날 뛴 줄넘기 횟수를 입력하고, 반 전체 그래프·학생별 누적을 보는 프로그램입니다.
**학교 시트에 껍데기(Shell.gs) 하나만 설치**하면, 화면과 기능은 이 페이지에서 열려 새 판이 나오면 자동으로 바뀝니다.

Made by 음악적체육인 · 학교·교육용 무료 (판매·광고 금지 — 아래 [사용 조건](#사용-조건) 참고)

## 처음 설치 (2분, 한 번만)

### 방법 A — 견본 시트 사본 만들기 (추천)
1. 아래 링크를 눌러 **사본 만들기** → 내 드라이브에 껍데기가 들어 있는 시트가 생깁니다.
   시트 왼쪽 위 이름 `줄넘기 기록 관리(견본)의 사본` 을 눌러 `6학년 1반 줄넘기`처럼 **우리 반 이름으로 바꿔** 주세요.
   👉 https://docs.google.com/spreadsheets/d/1ItPU6WU1-buXQ_Cb9yRYjUz81IYXISoq3ul3_ht-4h0/copy
2. 사본에서 **확장 프로그램 → Apps Script → 배포 → 새 배포 → 유형: 웹 앱**
   - 다음 사용자로 실행: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 → 권한 허용 (경고 화면이 나오면 "고급 → 안전하지 않은 페이지로 이동")
3. 나온 **웹 앱 주소**(…/exec)를 열면 "설치 확인" 화면이 뜹니다. **프로그램 열기** 를 누르고, 열린 주소를 **즐겨찾기**에 넣으면 끝! 관리자 비밀번호는 처음에 `1234` 입니다.

> 반마다 따로 쓰려면 반마다 견본 사본을 새로 만드세요. 다른 반이 **쓰던** 시트를 복사하면 학생·기록까지 따라옵니다.

### 방법 B — 직접 붙여넣기
1. 구글 드라이브에서 **새 스프레드시트**를 만들고 **확장 프로그램 → Apps Script** 를 엽니다.
2. 왼쪽 `Code.gs` 의 내용을 전부 지우고, **Shell.gs** 내용을 붙여넣은 뒤 저장(Ctrl+S)합니다.
3. 위 방법 A 의 2~3번과 같이 배포합니다.

학생들에게는 **관리자 메뉴 → 기본 설정 → 학생 접속 QR** 을 보여 주세요.

## 1.x 를 쓰던 학교에서 옮기기

학생과 기록은 같은 스프레드시트에 그대로 남습니다.

1. Apps Script 에서 `Code.gs` 내용을 **Shell.gs** 로 바꿔 붙여넣습니다.
2. `Index`, `StudentPage`, `AdminPage`, `ApprovalPage`, `AdminLogin`, `Styles` HTML 파일은 **삭제**해도 됩니다.
3. **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포** (주소가 그대로 유지됩니다)
4. 웹 앱 주소를 열고 **프로그램 열기** → 즐겨찾기.
5. 학생 QR은 관리자 메뉴의 새 QR로 한 번만 다시 알려 주세요. (예전 QR로 들어와도 "프로그램 열기" 버튼이 나옵니다)

> 이미 기록이 있는 학교는 승인 절차가 **꺼진 상태**로 이어집니다(새로 설치하면 기본 켜짐). 승인 후 반영을 원하면 관리자 메뉴 → 기본 설정 → 승인 절차를 켜세요. 전국 현황판에 참여하면 자동으로 켜집니다.

## 업데이트

- **화면·기능**: 자동. 따로 할 일이 없습니다. 바뀐 내용은 관리자 메뉴 → 업데이트 내역에서 볼 수 있어요.
- **껍데기(Shell.gs)**: 거의 바뀌지 않습니다. 바꿔야 할 때는 업데이트 내역 탭에 안내가 뜹니다.

## 문제가 생기면

- "학교 시트에 연결하지 못했어요" → 배포의 액세스 권한이 **모든 사용자**인지 확인하세요.
- 새 기능을 미리 써 보려면 `…/jumprope/beta/` 주소(시험판)를 이용하세요.

1. 새 스프레드시트 → 확장 프로그램 → Apps Script → `Collector.gs` 내용 붙여넣기
2. 배포 → 새 배포 → 웹 앱 (실행: 나 / 액세스: 모든 사용자)
3. 나온 `…/exec` 주소를 루트 `national.json` 과 `beta/national.json` 의 `"collector"` 에 넣고 올리기
